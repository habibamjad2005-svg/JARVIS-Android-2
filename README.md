# JARVIS-Android-2
Mobile AI Assistant – JARVIS with Gemini AI, Voice Commands and Multilingual Support. description
## JARVIS Android App Development

This project is for Android mobile phones only.

### Features
- Iron Man inspired JARVIS dashboard
- Gemini AI integration
- Voice input and voice responses
- Urdu, English and multilingual support
- Modern dark futuristic interface
- AI chat assistant
- Android permission-based phone assistance

### Development
- Platform: Android
- Language: Java
- Build system: Gradle
- Output: Installable APK

### Project Goal
Build a fully functional Android JARVIS AI assistant. No Windows or desktop version is required.
